# 2단계: 손금 해석 (호아 도사)

> 재미로 보는 손금입니다. 실제 성격·운명·건강과는 관계가 없어요. 모든 문구는 긍정적이고 부드럽게 씁니다.

1단계 YOLO11n-seg 모델(감정선·두뇌선·생명선·운명선 분할) 출력을 받아
**손금 특징 → 4가지 운 별점 → 12가지 여우 유형 → (선택) 친구 궁합** 을 만드는 투명한 규칙 기반 파이프라인입니다.

```
사진 ─ features.py ─▶ 특징 JSON ─ interpret.py + rules.yaml + calibration.yaml ─▶ 별점·유형 JSON ─ prompt_ko.md ─▶ LLM(호아 도사) 풀이
```

## 파일

| 파일 | 역할 |
|---|---|
| `features.py` | 사진 → 마스크 → 손금별 특징 JSON (`python interpret/features.py 사진.jpg`) |
| `rules.yaml` | 사람이 읽고 고칠 수 있는 규칙표 (운 별점 규칙, 유형 가중치, 궁합 점수, 이유 문구) |
| `calibration.yaml` | 자동 생성. 특징 백분위(10% 간격)와 유형 균형용 bias (`calibrate.py`) |
| `interpret.py` | 규칙 엔진: `interpret(feat)`, `compatibility(feat_a, feat_b)` |
| `extract_batch.py`, `calibrate.py` | 보정 세트(val 155장) 특징 추출 → 보정값 생성 |
| `prompt_ko.md` | 호아 도사 LLM 프롬프트 (system + user 템플릿, 6줄 출력) |
| `run_demo.py` | val 30장 데모 → `demo/results.jsonl`, `demo/type_distribution.md`, `demo/compat_examples.json`, `demo/overlay_*.png` |

### 모델 경로
`--model` 인자 > 환경변수 `PALM_MODEL` > 기본 `weights/best.pt` (v1). `.onnx` 도 가능.
v2 가 나오면: `PALM_MODEL=weights/v2/best.pt python interpret/run_demo.py`
(모델이 바뀌면 특징 분포가 달라지므로 `extract_batch.py --model ...` → `calibrate.py` 를 다시 돌리는 것을 권장)

CPU 사용: 단일 프로세스, `torch.set_num_threads(2)`, `OMP_NUM_THREADS=2`. 한 장당 약 1~2초.

## 1. 특징 (features.py)

**손바닥 좌표계** — 모든 길이는 손바닥 폭 W 로 나눔(사진 크기·거리 무관).
- 손 실루엣: 흰 배경 가정, (채도 + 어두움) Otsu 이진화 → 가장 큰 덩어리. 실패 시 손금 범위로 손바닥을 추정(fallback).
- 손바닥 폭 W: 감정선 높이 근처 몇 줄에서 손 실루엣 가로 구간의 중앙값(엄지는 보통 떨어져 있어 제외됨).
- 손가락 밑선(v=0): 위로 올라가며 폭이 0.75W 미만이 되는 줄, 감정선 기준 0.1~0.35W 위로 보정.
- 엄지 방향(왼손/오른손·좌우반전 무관): 투표 — 실루엣(엄지 덩어리) ×2, 감정선이 닿는 손 가장자리 ×1.5, 생명선 위쪽 끝 위치 ×1, 두뇌선 시작점-생명선 근접 ×1.
- `u`: 0 = 새끼손가락 쪽 가장자리, 1 = 엄지 쪽. `v`: 손가락 밑에서 손목 방향, W 단위.

**손금별** (마스크 합집합 → skeletonize → 8-이웃 그래프 → 가장 긴 경로)
| 특징 | 의미 |
|---|---|
| `present`, `confidence` | 검출 여부, 모델 최고 신뢰도 |
| `length`, `total_length` | 주 줄기 길이 / 끊긴 조각 포함 길이 (W 단위) |
| `bend`, `bend_signed`, `tortuosity` | 휨 정도(최대 처짐/현 길이), 방향, 굽이침 |
| `angle_deg` | 시작→끝 기울기 (0=수평, + = 손목 쪽으로 내려감) |
| `start_u/v`, `end_u/v`, `min/max_u/v` | 시작·끝 위치 (감정선: 새끼→검지, 두뇌선: 엄지쪽→바깥, 생명선: 위→손목, 운명선: 손목→위) |
| `thickness` | 마스크 면적 / 골격 길이 (W 의 %) — 굵기 |
| `clarity` | 0.6·신뢰도 + 0.4·굵기 — 선명도 대용 |
| `breaks` | 주 줄기 근처(0.35W 이내)의 추가 조각 수 = 끊김 |
| `branches` | 주 경로에서 0.05W 이상 뻗은 곁가지 수 |
| 감정선 `end_zone`, `end_rise` | 끝나는 손가락(ring/middle/index_middle/index, u 기준 근사), 끝이 위로 올라간 정도 |
| 두뇌선 `drop`, `reach_u` | 손목 쪽으로 내려간 정도(상상력), 새끼손가락 쪽까지 뻗은 정도 |
| 생명선 `arc_width`, `reach_v` | 호가 손바닥 안쪽으로 휘어 들어온 폭(1-min u), 아래로 뻗은 정도 |
| 운명선 `top_v`, `straightness` | 위로 올라간 지점, 곧음 |

**관계** (`relations`): `head_life_joined`(두뇌선 시작점이 생명선 0.07W 이내 → 붙음), `head_life_gap`,
`heart_head_distance`(겹치는 u 구간에서 평균 세로 간격), `simian_like`(간격 < 0.06W), `fate_present`, `fate_length`, `n_lines`.

## 2. 규칙 (rules.yaml)

전통 손금 해석(요약): 감정선 검지 아래 = 이상적·헌신적 사랑 / 중지 아래 = 실속형 / 그 사이 = 균형,
두뇌선 길고 곧음 = 논리·계획, 아래로 휨 = 상상력, 두뇌선·생명선 붙어 시작 = 신중 / 떨어짐 = 독립·자신감,
생명선 크게 휨 = 활력(수명과 무관), 운명선 뚜렷 = 목표 의식 / 없음 = 스스로 길을 만드는 타입, 가지 = 다재다능.
(참고: superstitionguide.com/palmistry/lines, HowStuffWorks "Palm Reading Lines", considerastrology.com heart line)

### 운 별점
별점 = `base 2.5` + 발동 규칙 `add` 합 → 반올림 → 1~5. 화면 이유는 `add ≥ 0` 규칙 중 최대 2개(없으면 기본 문구). `pct ≥ 0.7` = 보정 세트 상위 30%.

| 운 | 올려 주는 특징 (+) | 살짝 내리는 특징 (−0.5, 문구는 긍정형) |
|---|---|---|
| 재물운 | 운명선 있음 +0.5, 운명선 김 +0.5, 두뇌선 김 +0.5, 두뇌선 곧음 +0.5, 생명선 호 넓음 +0.5, 감정선 가지 +0.5 | 두뇌선 끊김, 두뇌선 짧음 ("재물이 활발히 들고 나는 흐름") |
| 연애운 | 감정선 검지 끝 +1, 검지·중지 사이 +0.5, 끝 상승 +0.5, 감정선 김 +0.5, 가지 +0.5, 선명 +0.5, 감정-두뇌 간격 넓음 +0.5 | 감정선 끊김("여러 번 찾아오는 설렘"), 짧음/없음("신중한 연애") |
| 건강운 (활력) | 생명선 호 넓음 +1, 김 +0.5, 선명 +0.5, 굵음 +0.5, 가지 +0.5 | 호 좁음·없음("에너지를 아껴 쓰는 차분한 타입"), 끊김("생활 리듬 변화") |
| 직업·성공운 | 운명선 있음 +1, 운명선 위까지 +0.5, 두뇌선 김 +0.5, 두뇌-생명 떨어짐 +0.5, 두뇌선 선명 +0.5, 감정선 검지 +0.25 | 운명선 없음 + 두뇌선 짧음("스스로 길을 만드는 타입") |

### 12 여우 유형
각 유형 점수 = Σ(가중치 × 0~1 신호) + bias → 최고점 유형. 동점이면 rules.yaml 순서가 앞선 유형.
bias 는 `calibrate.py` 가 보정 세트에서 12유형이 고르게 나오도록 반복 조정(현재 val 155장에서 유형당 12~13장).

| 유형 | 주요 신호 (가중치) |
|---|---|
| 황금손 재물여우 | 재물운 1.0, 두뇌선 곧음 0.5, 운명선 0.4, 두뇌선 길이 0.3 |
| 불꽃손 열정여우 | 생명선 호 폭 1.0, 감정선 끝 상승 0.5, 손금 굵기 0.5 |
| 달빛손 감성여우 | 두뇌선 하강 1.0, 두뇌선 휨 0.4, 감정선 상승 0.3 |
| 별빛손 지혜여우 | 두뇌선 길이 1.0, 두뇌선 곧음 0.5, 선명도 0.4 |
| 바람손 자유여우 | 두뇌-생명 떨어짐 0.6, 끊김 0.5, 운명선 없음 0.4, 감정선 상승 0.2 |
| 태양손 리더여우 | 감정선 검지 0.6, 운명선 길이 0.5, 직업운 0.5, 두뇌-생명 떨어짐 0.4 |
| 구름손 평화여우 | 두뇌-생명 붙음 0.9, 끊김 없음 0.4, 두뇌선 곧음 0.2, 감정-두뇌 간격 0.2 |
| 꽃잎손 인기여우 | 감정선 가지 0.8, 연애운 0.7, 감정선 길이 0.3 |
| 바위손 뚝심여우 | 굵기 1.0, 생명선 길이 0.5, 끊김 없음 0.3, 두뇌선 곧음 0.2 |
| 물결손 공감여우 | 감정-두뇌 간격 0.9, 감정선 길이 0.5, 감정선 상승 0.3 |
| 번개손 아이디어여우 | 가지 수 0.8, 두뇌선 휨 0.6, 끊김 0.3 |
| 은하손 행운여우 | 4운 평균 1.0, 운명선 0.5, 선명도 0.3 |

### 친구 궁합 `compatibility(a, b)` → 0~100
기본 62점 + 감정선 끝 같음 8 / 이웃 5, 두뇌선 기울기 비슷(<8°) 6 / 매우 다름(>20°, 보완) 5, 생명선 호 폭 비슷 4,
두뇌-생명 시작 같음 4 / 다름(팀워크) 3, 같은 원소 6 / 찰떡 원소쌍(불-바람, 태양-꽃, 달-물, 별-번개, 구름-바위, 금-은하 8점, 그 외 6점 쌍),
서로 보완되는 운(별 2개 이상 차이) 3×최대2. 최저 55점(항상 긍정적으로).

## 3. 데모 결과 (v1 best.pt)
`demo/type_distribution.md` 참고. val 30장: 유형별 0~5장 (표본이 작아 고르지 않음), 보정 세트 155장 전체: 유형별 12~13장.
별점은 대부분 3~4개, 1개는 나오지 않음(의도: 부정적 결과 최소화).

## 4. 한계 / 주의
- **운명선 불안정**: v1 모델의 운명선 mAP50 0.15, val 검출률 약 26%. 운명선 기반 규칙(재물·직업·황금/태양/은하)은 잡음이 큼.
- 생명선 예측이 실제 엄지 둘레 호가 아니라 손바닥 가운데 주름을 잡는 경우가 있음 → `arc_width` 신뢰도 낮음.
- 감정선 `end_zone` 은 손가락 위치를 검출하지 않고 손바닥 폭 비율로 근사 (경계 0.46/0.58/0.70). 모델이 감정선을 짧게 잡는 경향이 있어 'index' 는 드묾(약 5%).
- 끊김/가지 수는 마스크 조각·잔가지에 민감 (분할 품질에 좌우).
- 손바닥 추정은 흰/밝은 단색 배경 가정. 복잡한 배경의 실제 앱 사진은 fallback(손금 범위 기반)으로 동작하나 정확도 낮음 → 앱에서 촬영 가이드(밝은 배경, 손가락 위, 손바닥 전체) 권장.
- 보정(백분위·bias)은 val 155장에서 했고 데모 30장도 그 일부 → 분포 수치는 in-sample. 실제 사용자 사진 분포가 다르면 재보정 필요.
- `.pt` 와 `.onnx` 결과가 마스크 차이로 조금 다를 수 있음 (같은 사진에서 유형이 바뀔 수 있음).
- 규칙 표현식은 `eval` (builtins 없음) 로 평가 — rules.yaml 은 신뢰된 내부 파일로만 사용할 것.
