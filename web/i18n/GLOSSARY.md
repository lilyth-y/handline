# 번역 용어집 (Glossary) — 호아 도사 / Hoa the Fox Sage

이 파일은 4개 언어(ko·en·ja·zh-tw)의 문구를 일관되게 유지하기 위한 기준표입니다. 사전은 `public/js/i18n/<lang>.js`, 본문은 `i18n/content.<lang>.mjs`.
문구를 바꾸면 `node tools/gen_i18n.mjs` (정적 페이지) · `node tools/gen_share_og.mjs` (공유 OG/랜딩) · `node tools/export_i18n_texts.mjs` (LLM 프롬프트용 JSON)를 다시 돌리세요.

## 번역하지 않는 것 / 의도적으로 같은 것

- 회사명 mbox solutions, 도메인 hoadosa.com, 이메일 주소, Vercel/Supabase/Google AdSense 같은 서비스 이름.
- 내부 id(gold, fire …)와 URL 경로(/foxes/gold/ …)는 모든 언어 공통. 언어 접두어만 다르다 (/en/ /ja/ /zh-tw/, 한국어는 루트).
- `rules.yaml` / `rules.js` 의 한국어 원문은 손대지 않는다. 다른 언어 풀이 문구는 사전의 `reason.<id>` 키에 있고, 규칙/점수 계산은 언어와 무관하다.

## 한국어 전용 (다른 언어에는 없음)

- 광고: 카카오 애드핏, 쿠팡 파트너스, 후원(토스/카카오페이) — 외국어 페이지에서는 숨김/미게재. 구글 애드센스만 공통.
- 카카오톡 공유 버튼 (키가 비어 있어 현재도 숨김).
- 개인정보/약관의 쿠팡·후원·애드핏 문단.

## 알려진 한국어 원문 문제 (번역에는 반영하지 않음 — 확인 필요)

- 여우 도감 소개글이 "친구 궁합 풀이는 아직 준비 중"이라고 하지만 궁합 기능은 이미 있음 (한국어 원문 유지, 외국어 판은 "별도의 재미용 계산"으로 표기).
- 여우 메타 설명 조사 오류: "재물여우은", "에너지이" 등. 도감 본문 오타: "通한다"(한자), "실력로".
