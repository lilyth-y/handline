개인정보 안내

📷 손바닥 사진

사진은 내 폰(브라우저) 안에서만 분석해요. 서버로 보내거나 저장하지 않아요.

📊 익명으로 모으는 것

분석이 끝나면 아래 숫자만 보내요. 호아 도사의 ‘상위 %’ 기준을 실제 폰 사진에 맞게 다시 맞추는 데만 써요.

  • 손금선 측정값 (길이·휘어짐·선명도·시작/끝 위치 등, 손바닥 폭 기준 비율)
  • 결과 유형과 4가지 별점, 찾은 선 개수
  • 사진 가로·세로 크기, 앱·모델 버전, 기기 종류(카톡/모바일/PC)
  • 보낸 날짜 (시각은 기록하지 않아요)

👀 방문 통계

몇 명이, 어디서 들어왔는지는 Vercel Web Analytics로 익명 집계해요. 쿠키는 쓰지 않고, 페이지 열람·유입 경로·브라우저와 기기 종류, IP로 추정한 국가 단위 지역만 모아요. IP 주소 자체는 저장하지 않아요.

📣 광고

결과 화면 아래에 카카오 애드핏 또는 구글 애드센스 광고가 실릴 수 있어요. 광고는 각 제공자가 게재하며, 해당 정책에 따라 쿠키나 광고 식별자를 쓸 수 있어요. 자세한 내용은 카카오 개인정보 처리방침, 구글 개인정보처리방침, 구글 광고를 참고해 주세요.

🛒 쿠팡 파트너스

결과 화면에 쿠팡 파트너스 추천 링크가 보일 수 있어요. 링크를 통해 구매가 이루어지면 운영 주체 mbox solutions가 일정액의 수수료를 제공받을 수 있습니다. 이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.

🍙 후원

‘호아 도사에게 유부 사주기’ 버튼을 누르면 토스 또는 카카오페이 같은 송금·결제 페이지로 이동할 수 있어요. 후원은 선택 사항이며, 결제 정보는 해당 서비스의 정책에 따라 처리됩니다. 호아 도사는 카드 번호를 직접 받지 않아요.

🚫 모으지 않는 것

사진, 얼굴, 이름, 연락처, 계정, 기기 ID, IP 주소, 정확한 위치, 정확한 시각은 저장하지 않아요. 저장된 숫자만으로는 누구의 손인지 알 수 없어요. (보내는 순간의 서버 접속 기록은 보안을 위해 Supabase에 짧게 남았다가 자동으로 지워져요.)

🔒 보관과 이용

숫자는 Supabase 데이터베이스(서울 리전)에 보관하고, 앱에서는 보내기만 할 수 있고 읽을 수 없어요. 기준 보정 외 다른 용도로 쓰거나 제3자에게 팔지 않아요.

⚙️ 끄기

손금 측정 숫자의 익명 제공은 앱 화면의 개인정보 안내에서 끌 수 있어요. 끄면 그 기기에서는 손금 측정 숫자를 보내지 않아요. 설정은 해당 브라우저에 기억돼요. 방문 통계는 이와 별도로 익명 집계돼요.
