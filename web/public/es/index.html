    Aviso de privacidad

    📷 Tu foto de palma

    Su foto se analiza sólo dentro de su teléfono (browser). Nunca se carga o almacena.

    Lo que recopilamos anónimamente

    Cuando termina el análisis, enviamos solo números. Solo se usan para recalibrar la referencia «top %» de Hoa con fotos reales de móvil.

    • Mediciones de línea de palma (longitud, curva, claridad, posición de inicio/fino, como ratios de ancho de palma)
    • Su tipo de resultado, las 4 estrellas y el número de líneas encontradas
    • Foto, tabla, tabla, etc.
    • La fecha enviada (no se registra el tiempo del día)

    Estadísticas de visitas

    Contamos con visitas anónimas con Vercel Web Analytics. No se utilizan cookies; sólo recopilamos vistas de página, árbitros, tipo de navegador y dispositivo, y una región a nivel de país estimada en la dirección IP. La dirección IP en sí no está almacenada.

    ⋅ Ads

    Los anuncios de Google AdSense pueden aparecer debajo de la pantalla de resultado. Los anuncios son atendidos por el proveedor, que puede utilizar cookies o identificadores de publicidad bajo sus propias políticas.     Lo que no recogemos

    No almacenamos fotos, caras, nombres, datos de contacto, cuentas, ID de dispositivo, direcciones IP, ubicación exacta o hora exacta. Los números guardados por sí solos no pueden decirle a nadie cuya mano era. "Clase" (Un registro de acceso a servidor de corta duración hecho cuando se envían los números se mantiene brevemente en Supabase para seguridad y luego se elimina automáticamente.)

    🔒 Almacenamiento y uso

    Los números se almacenan en una base de datos Supabase (región Seúl). La aplicación sólo puede enviarlos, no leerlos. No se utilizan para nada más que la calibración y no se venden a terceros.

    ⚙ Apaga

    Cuando esté apagado, este dispositivo no enviará mediciones de palma. El ajuste se recuerda en este navegador. Las estadísticas de visitas se contabilizan anónimamente, por separado de esto.
