    隱私權說明

    📷 手掌照片

    照片只會在你的手機（瀏覽器）裡分析，不會上傳到伺服器，也不會儲存。

    📊 匿名蒐集的資料

    分析結束後，只會傳送下列數字。這些數字只用來把狐仙「前 %」的基準，重新調整成符合實際手機照片。

    • 手相線的測量值（長度、彎曲度、清晰度、起點／終點位置等，以手掌寬度為基準的比例）
    • 結果類型、4 項星等與找到的線條數量
    • 照片的寬與高、App 與模型版本、裝置種類（App 內瀏覽器／手機／電腦）
    • 傳送日期（不記錄時間）

    👀 訪客統計

    有多少人從哪裡來，是用 Vercel Web Analytics 匿名統計的。不使用 Cookie，只蒐集頁面瀏覽、來源、瀏覽器與裝置種類，以及由 IP 推估的國家層級地區。不會儲存 IP 位址本身。

    📣 廣告

    結果畫面下方可能會出現 Google AdSense 廣告。廣告由各提供者刊登，並可能依其政策使用 Cookie 或廣告識別碼。詳情請參考 Google 隱私權政策與 Google 廣告。

    🚫 不蒐集的資料

    不會儲存照片、臉孔、姓名、聯絡方式、帳號、裝置 ID、IP 位址、精確位置與精確時間。光憑儲存的數字，無法得知是誰的手。（傳送當下的伺服器連線紀錄，會為了安全短暫留在 Supabase，之後自動刪除。）

    🔒 保存與使用

    數字儲存在 Supabase 資料庫（首爾區域），App 只能傳送、無法讀取。除了校準基準之外不會用於其他用途，也不會賣給第三方。

    ⚙️ 關閉

    關閉後，這台裝置就不會再傳送手相測量數字。設定會記在這個瀏覽器裡。訪客統計則另外匿名統計。
