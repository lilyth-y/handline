    プライバシーのご案内

    📷 手のひらの写真

    写真はお使いのスマホ（ブラウザ）の中だけで解析します。サーバーへ送信したり、保存したりはしません。

    📊 匿名で集めるもの

    解析が終わると、次の数値だけを送信します。ホア仙人の「上位%」の基準を、実際のスマホ写真に合わせて調整し直すためだけに使います。

    • 手相の線の測定値（長さ・カーブ・濃さ・始点／終点の位置など。手のひら幅に対する比率）
    • 結果のタイプ、4つの星の数、見つかった線の本数
    • 写真の縦横サイズ、アプリ・モデルのバージョン、端末の種類（アプリ内ブラウザ／モバイル／PC）
    • 送信した日付（時刻は記録しません）

    👀 アクセス統計

    何人がどこから来たかは、Vercel Web Analytics で匿名集計しています。Cookie は使わず、ページの閲覧・流入元・ブラウザと端末の種類、IP アドレスから推定した国単位の地域だけを集めます。IP アドレス自体は保存しません。

    📣 広告

    結果画面の下に、Google AdSense の広告が表示されることがあります。広告は各提供事業者が配信し、そのポリシーに従って Cookie や広告 ID を使う場合があります。詳しくは Google プライバシーポリシー と Google 広告 をご覧ください。

    🚫 集めないもの

    写真、顔、名前、連絡先、アカウント、端末 ID、IP アドレス、正確な位置情報、正確な時刻は保存しません。保存された数値だけでは、だれの手なのかはわかりません。（送信する瞬間のサーバーのアクセス記録は、セキュリティのために Supabase に短期間だけ残り、自動的に削除されます。）

    🔒 保管と利用

    数値は Supabase のデータベース（ソウルリージョン）に保管します。アプリからは送信だけができ、読み出しはできません。基準の調整以外の目的には使わず、第三者に販売することもありません。

    ⚙️ オフにする

    オフにすると、この端末からは手相の測定数値を送信しません。設定はこのブラウザに記憶されます。アクセス統計はこれとは別に、匿名で集計されます。
