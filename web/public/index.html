개인정보 안내

📷 손바닥 사진

사진은 내 폰(브라우저) 안에서만 분석해요. 서버로 보내거나 저장하지 않아요.

📊 익명으로 모으는 것

분석이 끝나면 아래 숫자만 보내요. 호아 도사의 ‘상위 %’ 기준을 실제 폰 사진에 맞게 다시 맞추는 데만 써요.

  • 손금선 측정값 (길이·휘어짐·선명도·시작/끝 위치 등, 손바닥 폭 기준 비율)
  • 결과 유형과 4가지 별점, 찾은 선 개수
  • 사진 가로·세로 크기, 앱·모델 버전, 기기 종류(카톡/모바일/PC)
  • 보낸 날짜 (시각은 기록하지 않아요)

🚫 모으지 않는 것

사진, 얼굴, 이름, 연락처, 계정, 기기 ID, IP 주소, 위치, 정확한 시각은 저장하지 않아요. 저장된 숫자만으로는 누구의 손인지 알 수 없어요. (보내는 순간의 서버 접속 기록은 보안을 위해 Supabase에 짧게 남았다가 자동으로 지워져요.)

🔒 보관과 이용

숫자는 Supabase 데이터베이스(서울 리전)에 보관하고, 앱에서는 보내기만 할 수 있고 읽을 수 없어요. 기준 보정 외 다른 용도로 쓰거나 제3자에게 팔지 않아요.
