    隐私权说明

    📷 手掌照片

    照片只会在你的手机（浏览器）里分析，不会上传到伺服器，也不会储存。

    📊 匿名搜集的资料

    分析结束后，只会传送下列数字。这些数字只用来把狐仙「前 %」的基准，重新调整成符合实际手机照片。

    • 手相线的测量值（长度、弯曲度、清晰度、起点／终点位置等，以手掌宽度为基准的比例）
    • 结果类型、4 项星等与找到的线条数量
    • 照片的宽与高、App 与模型版本、装置种类（App 内浏览器／手机／电脑）
    • 传送日期（不记录时间）

    👀 访客统计

    有多少人从哪里来，是用 Vercel Web Analytics 匿名统计的。不使用 Cookie，只搜集页面浏览、来源、浏览器与装置种类，以及由 IP 推估的国家层级地区。不会储存 IP 位址本身。

    📣 广告

    结果画面下方可能会出现 Google AdSense 广告。广告由各提供者刊登，并可能依其政策使用 Cookie 或广告识别码。详情请参考 Google 隐私权政策与 Google 广告。

    🚫 不搜集的资料

    不会储存照片、脸孔、姓名、联络方式、帐号、装置 ID、IP 位址、精确位置与精确时间。光凭储存的数字，无法得知是谁的手。（传送当下的伺服器连线纪录，会为了安全短暂留在 Supabase，之后自动删除。）

    🔒 保存与使用

    数字储存在 Supabase 资料库（首尔区域），App 只能传送、无法读取。除了校准基准之外不会用于其他用途，也不会卖给第三方。

    ⚙️ 关闭

    关闭后，这台装置就不会再传送手相测量数字。设定会记在这个浏览器里。访客统计则另外匿名统计。
